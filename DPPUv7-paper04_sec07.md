## 7. Discussion and Outlook

本節では、本稿の結果の含意と今後の展開を整理する。

### 7.1 本稿で固定できたこと

本稿により、4 つの Thurston 幾何を同一の比較枠組みに載せるための最小限ではなく、かなり強い辞書が固定された。first layer では 36-entry bulk inventory が閉じ、Maxwell universality の上に geometry-dependent activation rule が乗ることが明示された。second layer では spectral / torsional-charge / inflow の 3 family が明確に分離され、さらに pairwise cobordism dictionary により 6 つの pair のすべてが比較可能な形に整理された。

この整理により、 $Nil^3$ は strict な local APS spectral core を担う geometry、 $S^3$ は frame-bundle-normalized torsional-charge core を担う geometry、 $T^3$ は trivial spectral benchmark、 $Sol^3$ は compact quotient と spin structure に依存した global spectral branch を持ちうる geometryとして位置づけられる。ここで重要なのは、spectral family の内部でも source を区別する必要がある点である。 $Nil^3$ は local Levi-Civita spinor CS により値が固定されるのに対し、 $Sol^3$ の spectral entry は global kernel / spin data によって立ち上がる。scaffold layer は、この source の違いと background geometry の distinctness を同時に記述するために必要である。

さらに、same Euclidean circle に対して KK reading と Matsubara-style thermal reading を併置したことで、主辞書を保ったまま reduced description と thermal description を付加できることも明確になった。これは本稿の主結果が Euclidean response dictionary そのものであり、二つの読みはその secondary interpretation であることを示している。

### 7.2 将来の展開

今後の直接的な延長としては、少なくとも次の 3 系統がある。

1. **Lorentzian extension**  
   本稿で固定した Euclidean response dictionary を Lorentzian setting に持ち上げれば、protected / activated structure のうちどれが real-time observable に残るかを判定できる可能性がある。とくに parity-odd transport, interface response, thermal interpretation のうち何が解析接続に耐えるかは、次段階で明確化すべき論点である。

2. **現象論への適用**  
   本稿の辞書は抽象的な geometry 分類に留まらず、metastable branch, rolling branch, no-support branch のような現象論的ラベルに対して、どの response channel が期待されるかを整理する基盤にもなりうる。bulk activation と boundary observable を同時に使うことで、単独の effective coefficient では見えない幾何依存性を整理できる余地がある。

3. **Sol compact quotient / spin structure 依存性の一般化**  
   本稿では $Sol^3$ の boundary spectral entry を compact mapping-torus benchmark 上で strict 化したが、一般の hyperbolic monodromy や quotient family に対して kernel structure がどこまで変わるかは今後の課題である。今回固定した local/global dichotomy が Sol family 全体でどのように一般化されるかを明示することは、borderline な spectral entry を扱う上で次の自然なステップである。
