## 8. Conclusion

本論文では、4 つの Thurston 幾何 $T^3$, $Nil^3$, $S^3$, $Sol^3$ を対象として、Euclidean geometric response dictionary と selection rules を構成した。主結果は、response を two-layer structure として整理し、bulk inventory と boundary / cobordism inventory を幾何横断で閉じた点にある。

first layer では 36-entry bulk inventory とその selection rule を与えた。ここでは Maxwell coefficient が

$$
K_{\rm Mxw}=-\frac{L^2}{2r_0^4}
$$

として 4 geometry に共通である一方、CS activation, Higgsing pattern, EC slice-minimum structure, reduced $\eta$-mode defect-localization benchmark の活性化条件は geometry 依存に分岐することを示した。 $Nil^3$ は CS+EC activated geometry、 $S^3$ は最も豊かな CS / Higgsing activated geometry、 $T^3$ は inert benchmark、 $Sol^3$ は CS-inert / EC-active かつ rigid scaffold を持つ geometry として整理される。

second layer では spectral, torsional-charge, inflow の 3 family と pairwise cobordism dictionary を固定した。とくに $Nil^3$ の strict local APS core、 $S^3$ の frame-bundle-normalized torsional-charge core、 $T^3$ の trivial spectral benchmark、そして compact Sol benchmark 上の spin-sensitive global spectral branchは、本稿の比較辞書の中心をなす。これにより spectral family の内部で local source と global source が区別されることが明確になった。geometric scaffold layer は、この source の違いを background geometry の distinctness と切り分けて記述する役割を持つ。

さらに、Euclidean circle に対する二つの読みとして KK reduction reading と Matsubara-style thermal reading を併記した。これらは、それぞれ reduced description と thermal description を与えるが、理論的に同一の reading として同一視されるわけではない。両者は、すでに構成された Euclidean response dictionary の secondary interpretation として共存する。

以上により、本稿は、4 geometry の allowed, protected, activated response を一貫した rule set として与える Euclidean geometric response dictionary を提示する。4 つの Thurston 幾何を同一の比較枠組みに置いたとき、bulk, boundary, cobordism, circle readings の各層がどのように整理されるかを明示したことが、本稿の主要結論である。
